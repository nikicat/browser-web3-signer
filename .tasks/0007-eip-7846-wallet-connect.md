# Revisit EIP-7846 `wallet_connect`

## Goal
EIP-7846 standardizes the account-switch flow that ADR 0005 (`docs/adr/0005-evm-account-change.md`) works
around per wallet. Blocked on wallet adoption: none of the wallets checked implemented it
(2026-07). Re-check MetaMask, Rabby, Ambire, Brave sources; adopt it once supported.
